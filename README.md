# 🎉 Event Booking and Venue Management System

A full-stack web application built using **Flask** and **MySQL**, designed to simplify event venue booking and management for users, while providing powerful administrative tools for event organizers.

---

## 📌 Project Overview
This system enables users to:
- Register and log in
- Browse and book upcoming events
- Make payments using various methods
- View booking history and profile details

Admins can:
- Add or delete events
- Manage FAQs posted by users
- Track user booking/payment history
- View revenue reports and handle event logistics

---

## 🚀 Features

### 👥 User Features
- Sign up / login / logout
- Browse event listings with details
- Book events and specify guest count
- Pay using Credit/Debit Card, UPI, PayPal, or Cash
- View personal booking history
- Ask questions via FAQ

### 🛠️ Admin Features
- Add/Delete events
- View event-wise revenue
- Manage and respond to FAQ submissions
- Access user booking/payment history
- Dedicated admin dashboard with analytics

---

## 🗃️ Tech Stack
- **Backend**: Flask (Python)
- **Frontend**: HTML, Bootstrap, Jinja2 Templates
- **Database**: MySQL
- **Other Tools**: SweetAlert, SQL Views & Triggers

---

## ⚙️ Installation & Setup

### 💾 Requirements
- Python 3.x
- MySQL Server
- `pip install flask mysql-connector-python`

### 🧰 Steps
1. Clone the repo:
   ```bash
   git clone https://github.com/your-username/your-repo.git
   cd event_system
   ```

2. Import the database schema:
   - Open MySQL Workbench or CLI
   - Run: `schema.sql`

3. Start the Flask app:
   ```bash
   python app.py
   ```

4. Access it locally:
   - Navigate to `http://127.0.0.1:5000`
